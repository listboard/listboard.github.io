Backup everything, as one JSON file

Tasks live only in this browser, so they do not follow you to another machine and clearing site data takes them with it. Export writes the whole board out; import merges a file back in without deleting anything that is already here.

The archive

Archiving is how a task leaves a board without leaving Listboard. Archived tasks keep their lane, their comments and their history, and are reachable from List → Status → Archived, where any of them can be reopened back into the lane it left.

Danger zone

These are permanent and are not covered by undo. Export first.
